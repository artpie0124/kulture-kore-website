# 스페이스클라우드 예약 → 고객 안내 문자 자동 발송 시스템

와리프 소극장([스페이스클라우드 공간 페이지](https://www.spacecloud.kr/space/73075))에 예약이 들어오면,
고객에게 **출입 비밀번호·주차 안내 등 이용 안내 문자를 자동으로 발송**하는 시스템입니다.

스페이스클라우드는 외부 연동용 API를 제공하지 않기 때문에, 호스트에게 오는
**예약 알림 이메일**을 Gmail에서 감지하는 방식으로 동작합니다.

```
스페이스클라우드 예약 확정
   → 호스트 Gmail로 예약 알림 메일 도착
   → Google Apps Script가 5분마다 새 메일 확인
   → 메일에서 예약자 이름/연락처/일시 추출
   → 발송 (아래 방식 중 CONFIG.PROVIDER로 선택)
   → 처리한 메일에 "문자발송완료" 라벨 부착 (중복 방지)
   → 실패 시 관리자에게 알림 메일 발송
```

## ✅ 실제 운영 구성 (2026-07 완료)

최종적으로 채택된 발송 방식은 **`phone` — 운영자의 안드로이드 폰(MacroDroid 앱)으로 직접 발송**입니다:

- Apps Script가 MacroDroid **웹훅 URL**(스크립트 속성 `PHONE_WEBHOOK_URL`)을 호출하면,
  폰의 MacroDroid 매크로(웹훅 트리거 → SMS 전송, 변수 `to`/`text`)가 문자를 발송합니다
- 건당 비용 0원 (문자 무제한 요금제 기준), 발신번호 = 운영자 폰 번호
- 주의: 폰이 켜져 있고 인터넷에 연결되어 있어야 하며, MacroDroid는
  배터리 최적화 예외(설정 → 앱 → MacroDroid → 배터리 → 제한 없음)로 등록해야 합니다
- **뿌리오 API는 사용 불가로 판명**: 뿌리오는 발송 서버 IP 사전등록이 필수인데
  (미등록 시 오류 3003 "invalid ip"), Apps Script(구글 서버)는 고정 IP가 없습니다.
  아래 뿌리오/알리고/솔라피 안내는 대안 기록용으로 남겨둡니다.

- 서버가 필요 없고 유지비 0원 (문자 발송 비용만 발생: SMS 건당 약 9~20원)
- 파일: [`Code.gs`](./Code.gs) — Apps Script 전체 코드

## 1단계. 문자 발송 API 준비 (뿌리오 — 기존 사용 중 계정 활용)

이미 뿌리오를 사용 중이므로 새로 가입할 필요 없이 **API 사용 신청만** 하면 됩니다.
발신번호도 이미 등록되어 있다면 그대로 사용됩니다.

1. [뿌리오](https://www.ppurio.com) 로그인
2. **문자 API(연동 관리) 메뉴**에서 API 사용 신청 → **API Key 발급** (키를 복사해 두세요)
3. **⚠️ 연동 IP 등록 항목이 있는 경우**: 이 시스템은 구글 서버(Google Apps Script)에서
   발송 요청을 보내는데, 구글 서버는 고정 IP가 없습니다. API 설정에 "연동 IP 등록"이
   필수로 되어 있다면 뿌리오 고객센터에 다음과 같이 문의하세요:
   > "API 발송을 이용하려는데 발송 서버의 IP가 유동적입니다. IP 제한 없이 사용하거나
   > IP 대역 등록으로 사용할 방법이 있나요?"
   - 만약 뿌리오가 고정 IP를 반드시 요구한다면, 자동 발송용으로만
     [솔라피](https://solapi.com)(IP 제한 없음)를 사용하는 것이 현실적인 대안입니다.
4. 잔액(충전금)이 충분한지 확인 — 안내 문자는 LMS(장문) 기준 건당 약 30원

### 대안 업체 (뿌리오 API 사용이 어려울 때)

- **솔라피**: [solapi.com](https://solapi.com) 가입 → 발신번호 등록 → API Key + Secret 발급.
  `CONFIG.PROVIDER`를 `'solapi'`로 변경. IP 제한이 없어 Apps Script와 궁합이 좋고,
  카카오 알림톡 확장에도 유리합니다.
- **알리고**: [smartsms.aligo.in](https://smartsms.aligo.in) 가입 후 `CONFIG.PROVIDER`를
  `'aligo'`로 변경. API 설정에서 IP 제한을 사용하지 않아야 합니다.

## 2단계. Apps Script 설치

1. **예약 알림을 받는 Gmail 계정으로 로그인**한 상태에서 [script.google.com](https://script.google.com) 접속
2. **새 프로젝트** 클릭 → 프로젝트 이름을 `와리프 예약문자 자동발송` 등으로 변경
3. 기본으로 있는 코드를 모두 지우고, [`Code.gs`](./Code.gs) 내용 전체를 붙여넣기
4. 저장 (Ctrl+S)

## 3단계. API 키 등록 (스크립트 속성)

API 키는 코드에 직접 적지 않고 "스크립트 속성"에 안전하게 저장합니다.

1. Apps Script 편집기 왼쪽 톱니바퀴 **프로젝트 설정** 클릭
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가**
3. 다음 항목을 추가:

| 속성 이름 | 값 | 비고 |
|---|---|---|
| `SENDER_PHONE` | `0212345678` | 뿌리오에 등록된 발신번호 (하이픈 없이) |
| `PPURIO_ACCOUNT` | 뿌리오 로그인 아이디 | 뿌리오 사용 시 (기본) |
| `PPURIO_API_KEY` | 뿌리오에서 발급받은 API Key | 뿌리오 사용 시 (기본) |
| `ALIGO_API_KEY` | 알리고에서 발급받은 키 | 알리고 사용 시 |
| `ALIGO_USER_ID` | 알리고 로그인 아이디 | 알리고 사용 시 |
| `SOLAPI_API_KEY` | 솔라피 API Key | 솔라피 사용 시 |
| `SOLAPI_API_SECRET` | 솔라피 API Secret | 솔라피 사용 시 |

## 4단계. 문자 내용 수정

`Code.gs` 상단 `CONFIG.MESSAGE_TEMPLATE`에서 `[ ]`로 표시된 부분을 실제 정보로 채우세요:

- `[극장 주소 입력]` → 와리프 실제 주소
- `[비밀번호 입력]` → 출입 비밀번호
- `[주차 안내 입력]` → 주차 안내
- `[극장 연락처 입력]` → 문의 전화번호

`{이름}` `{날짜}` `{시간}` `{공간명}`은 예약 정보로 자동 치환되니 그대로 두세요.

문자에는 **공간 매뉴얼 링크**(Google Drive)가 함께 발송됩니다. 링크가 포함되면 문자 길이가 90바이트를 넘으므로 자동으로 LMS(장문)로 전환됩니다. 매뉴얼 파일을 교체하려면 `MESSAGE_TEMPLATE`의 `공간 매뉴얼:` 줄에 있는 URL만 새 링크로 바꾸세요. (드라이브 파일 공유 설정은 "링크가 있는 모든 사용자 — 뷰어"로 두어야 고객이 열 수 있습니다.)

> 💡 **보안 팁**: 출입 비밀번호가 고정이라면 문자가 공유되면서 퍼질 수 있습니다.
> 주기적으로 비밀번호를 바꾸고 그때마다 템플릿도 함께 수정하세요.

## 5단계. 테스트

코드 편집기 상단의 함수 선택 드롭다운에서 함수를 골라 **실행** 버튼으로 실행합니다.
처음 실행 시 Google 권한 승인 창이 뜨면 **허용**하세요 (Gmail 읽기 + 외부 API 호출 권한).

1. **`sendTestSms` 실행** — 코드 안의 `myPhone`을 본인 번호로 바꾼 뒤 실행.
   처음에는 `DRY_RUN: true` 상태라 로그로만 확인됩니다. 로그 내용이 맞으면
   `CONFIG.DRY_RUN`을 `false`로 바꾸고 다시 실행 → 본인 폰에 실제 문자가 오는지 확인.
2. **실제 예약 알림 메일이 도착한 뒤 `testParse` 실행** — 메일에서 이름/전화번호/일시가
   제대로 추출되는지 로그로 확인. 추출이 안 되면 아래 "메일 형식 조정" 참고.

## 6단계. 자동 실행 켜기

1. `setup` 함수를 한 번 실행 → 5분마다 자동으로 새 예약 메일을 확인합니다
2. 첫 실제 예약이 들어오면 Gmail에서 해당 메일에 `스페이스클라우드/문자발송완료`
   라벨이 붙었는지, 고객에게 문자가 갔는지 확인하세요

## 메일 형식 조정 (예약 알림 메일이 예상과 다를 때)

실제 예약 알림 메일을 아직 받아본 적이 없어서, 파싱 코드는 일반적인 형식
(예약자명, 010 전화번호, 날짜, 시간)을 폭넓게 인식하도록 작성되어 있습니다.
실제 메일이 도착했는데 `testParse` 결과가 이상하다면:

- **검색이 안 됨** → `CONFIG.SEARCH_QUERY`의 `subject:(예약)`을 실제 메일 제목에 맞게 수정
- **발송 대상으로 인식 안 됨** → `CONFIG.CONFIRM_KEYWORDS`에 실제 메일의 문구 추가
- **이름/날짜/시간 추출 실패** → `parseReservation_()` 함수의 정규식을 실제 본문에 맞게 수정
- **전화번호가 메일에 아예 없음** → 이메일 방식으로는 자동화 불가.
  이 경우 다른 접근(호스트센터 확인 등)이 필요하니 다시 상담하세요.

## 자주 묻는 질문

**Q. 문자 대신 카카오 알림톡으로 보낼 수 있나요?**
가능합니다. 솔라피 가입 + 카카오 채널 개설 + 템플릿 심사(영업일 2~3일)가 필요합니다.
알림톡은 건당 6~8원으로 더 저렴하고 신뢰도가 높습니다. 우선 문자로 시작한 뒤 전환을 추천합니다.

**Q. 같은 예약에 문자가 두 번 갈 수 있나요?**
처리한 메일에 라벨을 붙여 중복을 방지합니다. 라벨을 수동으로 제거하면 재발송될 수 있으니
Gmail에서 `스페이스클라우드/` 라벨은 건드리지 마세요.

**Q. 파싱에 실패하면 고객이 문자를 못 받나요?**
네, 그래서 실패 시 관리자(`artpie0124@gmail.com`)에게 "수동 확인 필요" 메일이 자동 발송됩니다.
해당 메일에는 `스페이스클라우드/확인필요` 라벨이 붙습니다.

**Q. 비용이 얼마나 드나요?**
Google Apps Script는 무료입니다. 문자 비용만 발생: 안내 문자는 길이상 LMS(장문)로 나가며
알리고 기준 건당 약 27원 — 월 100건 예약 시 약 2,700원 수준입니다.
