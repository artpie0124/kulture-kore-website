# 스페이스클라우드 예약 자동 감지 → 안내 문자 자동 발송 (상시가동 버전)

사장님 PC에서 상시 실행되는 프로그램이 스페이스클라우드 호스트센터에 로그인 상태로
접속해, 새 예약이 들어오면 **예약자 연락처를 읽어와 고객에게 안내 문자를 자동 발송**합니다.

스페이스클라우드가 예약 알림 메일/알림톡에 고객 전화번호를 넣어주지 않기 때문에,
프로그램이 호스트센터 예약 상세 페이지에서 직접 번호를 읽어오는 방식입니다.
(공간히어로 등 상용 서비스와 같은 원리)

```
[사장님 PC의 감시 프로그램]
   로그인된 상태로 호스트센터 "예약 관리 리스트" 접속
   → 상태가 '예약확정'인 새 예약 감지 (목록에 예약자 연락처가 노출됨)
   → MacroDroid 웹훅 호출 → 사장님 폰이 고객에게 문자 발송 📱
```

문자 발송은 이미 설정해둔 **폰(MacroDroid) 방식을 그대로 재사용**합니다.

**핵심**: 호스트센터 예약 목록에서 상태가 `예약확정`인 예약은 예약자 이름·전화번호가
그대로 노출됩니다(취소·이용완료 예약은 가려짐). 그래서 상세 페이지에 들어가지 않고
목록만 읽어도 새 예약의 번호를 얻을 수 있어, 빠르고 안정적입니다.

---

## ⚠️ 먼저 알아두실 점 (솔직한 안내)

- **PC를 24시간 켜두어야** 합니다. PC가 꺼지면 자동발송도 멈춥니다.
- **로그인은 처음 1회 직접** 해줘야 하고, 세션이 만료되면(수주~수개월) 다시 로그인해야 합니다.
- **스페이스클라우드가 사이트를 개편하면 멈출 수 있습니다.** 그때는 코드 보정(개발자 도움)이 필요합니다.
- 자동 접근을 과도하게 자주 하면 계정 제재 위험이 아주 약간 있습니다. 기본값(2분 간격)은 안전한 수준입니다.
- 이 방식이 부담되면, 공간히어로의 자동 메시지 기능(요금제 포함 여부 확인) 또는
  반자동(번호 복사 → 폰 버튼 탭)이 더 편할 수 있습니다.

## 설치·실행 순서 (윈도우 기준)

### 준비물: Node.js 설치
[nodejs.org](https://nodejs.org) 에서 **LTS 버전**을 내려받아 설치하세요 (기본값으로 계속 눌러 설치).

### 0. 폴더 준비
이 `spacecloud-auto` 폴더를 통째로 PC의 원하는 위치(예: 바탕화면)에 복사하세요.

### 1. `설치.bat` 더블클릭 — 최초 1회
필요한 프로그램과 브라우저 구성요소를 자동으로 내려받습니다. "설치 완료"가 뜨면 됩니다.

### 2. `로그인.bat` 더블클릭 — 최초 1회
- 크롬 창이 뜨면 **평소처럼 호스트센터에 로그인**하세요 (네이버/카카오/애플 무엇이든 OK)
- 예약 목록 화면까지 들어간 뒤, **검은 창으로 돌아와 엔터 키**를 누르세요
- "로그인 세션을 저장했습니다"가 뜨면 성공

### 3. `구조확인.bat` 더블클릭 — (선택) 문제 생겼을 때만
- 예약 화면 구조가 예상과 다르거나 예약이 감지되지 않을 때, 페이지 구조를 파일로 저장합니다.
- 그 결과(`discover_list_text.txt`)를 개발자에게 보내면 추출 코드를 보정할 수 있습니다.
- 평소에는 건너뛰어도 됩니다 (실제 예약 목록 형식에 맞춰 이미 코드가 작성되어 있음).

### 4. `시작.bat` 더블클릭 — 평소 운영
- 검은 창이 뜨고 "감시 시작"이 나오면 작동 중입니다.
- **이 창을 열어둔 동안** 2분마다 새 예약을 확인하고 자동으로 문자를 보냅니다.
- 창을 닫으면 멈춥니다. PC 켤 때마다 이 파일을 실행하면 됩니다.
  (자동 시작 등록을 원하면 개발자에게 요청하세요.)

## 설정 바꾸기 (`config.js`)

- `MESSAGE_TEMPLATE` — 고객에게 보낼 문자 내용 (주소/비밀번호/문의처)
- `SPACE_FILTER` — 이 단어가 포함된 예약만 처리 (현재 `'와리프'`)
- `POLL_INTERVAL_SEC` — 확인 주기(초). 기본 120초
- `PHONE_WEBHOOK_URL` — 문자 발송용 MacroDroid 웹훅 주소

## 문제 해결

- **"로그인이 만료되었습니다"** → `로그인.bat` 다시 실행
- **문자가 안 감** → 발송용 폰이 켜져 있고 MacroDroid가 살아있는지 확인, `config.js`의 웹훅 주소 확인
- **예약 링크를 못 찾음** → 사이트 구조가 바뀐 것. `구조확인.bat` 결과를 개발자에게 전달해 보정
- **같은 예약에 문자가 또 감** → `processed.json`(처리 기록)을 지우면 초기화됨 (주의)

## 파일 설명

| 파일 | 역할 |
|---|---|
| `설치.bat` | 최초 설치 |
| `로그인.bat` | 호스트센터 로그인 (세션 저장) |
| `구조확인.bat` | 예약 페이지 구조 덤프 (보정용) |
| `시작.bat` | 상시 감시 시작 |
| `config.js` | 설정 (문자 내용 등) |
| `login.js` / `discover.js` / `watch.js` | 실제 동작 코드 |
| `session.json` | 로그인 세션 (자동 생성, 공유 금지) |
| `processed.json` | 처리한 예약 기록 (자동 생성) |
